# 🧘 Maya RPG — Aplicativo de Fisioterapia

Aplicativo Android desenvolvido para a Clínica Maya, com foco em exercícios de RPG (Reeducação Postural Global). O app permite que pacientes acessem seu plano de exercícios de forma simples e intuitiva.

## 📱 Como Instalar e Testar

### Pré-requisitos
- Android Studio instalado
- Dispositivo Android ou emulador com API 24 ou superior

### Passos
1. Clone o repositório:
```
   git clone https://github.com/2026-1-NCC3/Projeto9.git
```
2. Abra o projeto no **Android Studio**
3. Aguarde o **Gradle Sync** finalizar
4. Clique em **Run ▶️** para instalar no dispositivo ou emulador

### Como testar a função principal
1. Abra o app e clique em **ENTRAR** na tela de login
2. No menu principal, clique em **TÉCNICAS**
3. Clique em **POSTURA**
4. Clique em **INICIAR TUTORIAL GUIADO**
5. Acompanhe os 3 GIFs de exercício (40 segundos cada)
6. Ao finalizar, veja as **calorias estimadas** na tela

---

## ✅ Funcionalidades Implementadas

- **Tela de Login** — tela inicial com campos de email e senha
- **Menu Principal** — navegação para as seções do app
- **Técnicas RPG** — listagem das técnicas disponíveis
- **Tutorial de Postura** — visualização de 3 exercícios em sequência via GIFs animados (40s cada), com barra de progresso, timer e controle de iniciar/pausar/retomar
- **Calorias Estimadas** — cálculo simples de calorias ao completar a sessão (10 kcal por sessão)
- **Ícone de Perfil** — tela de perfil do usuário
- **Ícone de Home** — tela de Menu principal
